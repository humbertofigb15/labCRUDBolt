# VERA User Management CRUD

CRUD application developed in React and TypeScript for the VERA challenge.

The application allows users to:

- Create users
- View user information
- Edit users
- Delete users
- Search and filter users

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- LocalStorage
